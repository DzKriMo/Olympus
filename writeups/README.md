## Difficulty Levels
Note that the solution for each challenge changes based on the machine's difficulty setting:
- **Easy:** Direct exploitation with hints provided.
- **Medium:** Basic blacklists and filters are in place, requiring bypasses.
- **Hard / Nightmare:** Robust security measures are implemented, requiring complex chains or a focus on other entry points.
